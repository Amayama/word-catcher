# Word Catcher · 听音抓词 (v0 prototype)

Listening game mock: the speaker says an English word, words fly in the purple
nebula — pinch (thumb + index) in the air to catch the word you heard.

- Top half: scene + word particles (Canvas)
- Bottom half: your live camera (MediaPipe hand tracking, on-device)
- Fallback: mouse mode if no camera

Built as an interactive mock for FLU-1803. Art is placeholder CSS; the real
version will use a Veo-generated background loop.
